# ContextPilot implementation record

The retained [original specification](product-specification.txt) defines a local-first Rust CLI/shared engine, SQLite persistence, authenticated dashboard, recoverable context and honest optional provider integration. Implementation has continued beyond the initial MVP; current verification evidence belongs in [verification.md](verification.md), without stale hard-coded test counts here.

Directory token totals count eligible full UTF-8 files with explicit analyzed-file/coverage metadata; directory CLI tokenization, retrieval and indexing respect exact-root project overrides. Scan limits fail rather than return partial totals.

Implemented offline: conservative prompt optimization; bundled verified text-encoding mappings with labeled fallback; configurable context budgets/overheads; project registration/partial overrides; ignored-aware persistent repository metadata index with symbols/imports/ranking; current source attachment with reuse/stale removal/recovery; transactional checkpoints/handoff; dated user model/pricing metadata; normalized provenance-bearing usage import; grouped analytics and supplied controlled quality/retry evidence; efficiency instruction export; optional prompt logging and managed-storage controls; generated JSON Schemas; static dashboard/CLI/API flows and backup/restore.

Provider adapters support explicit text generation and Anthropic remote counting, secret redaction, safe bounded HTTP handling, normalized usage and native OS credential storage with environment precedence. Offline mocks verify these interfaces without API keys. A configured key is not proof of authenticated access. No live paid request has been verified. An explicit macOS Apple Silicon native-vault roundtrip passed using a unique nonsecret probe, with deletion confirmed and no existing provider keys read.

Configurable controls have different scopes. Context thresholds, reserves/overheads, storage/external permissions, ignored paths, CLI/project file/excerpt-token budgets and inline report limits are enforced locally. Owned tool-output processing uses the configured target without dropping protected lines/status. Verbosity, external tool-output targets, subagent concurrency and verification preferences are exported instructions; no external agent process is controlled. The tool preserves critical output instead of blindly truncating it to a character limit. Schema export covers shared Rust data contracts, not a complete OpenAPI specification.

Token savings are measured prompt-size changes under one selected tokenizer. Provider overhead, estimated costs and unknown categories stay separate. Analytics pair only declared comparable controlled observations and do not infer causality/statistical significance. Repository symbols/import relationships use deterministic heuristics; parsable Rust excerpt boundaries use `syn` containing-function spans, with explicit whole-file fallback for other/unparseable languages. Scans are bounded at 20,000 files / 128 MiB.

Cross-target source compilation and binary linking were achieved for Intel macOS, Linux x86_64 and Windows x86_64 with isolated local toolchains. This does not substitute for executing on those platforms; see [platform verification](platform-verification.md). Other target OS vault/permission behavior remains a runtime validation gate. No publication, deployment, remote CI run or external agent mutation was performed.

MIT was explicitly selected by the owner. ContextPilot remains a provisional working name: existing projects use the same name in closely related areas. See [naming review](naming-review.md); no trademark or package-name clearance is claimed. Credentials/explicit paid-call consent, target OS runtime access and a cleared distribution identity are the remaining external prerequisites for those validation/release activities, rather than unfinished offline implementations of those interfaces.
